# Family Hub – frontend

React + Vite + TypeScript + Mantine. See the repo root `CLAUDE.md` for conventions.

```powershell
npm install
npm run dev      # http://localhost:5173 – proxies /api to Spring Boot on :8080
npm run lint     # oxlint
npm test         # vitest
npm run build    # tsc + vite build -> dist/
```
